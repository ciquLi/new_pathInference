# 实现与产物边界

当前正式路径为：日期登记 → 同日输入与模型核验 → 源ρ分组 → 邻居选择和固定5个递归候选 → 公开规则约束的完整前缀树 → TRAIN尾段拼接 → 255维路径评分与入库 → PATS训练／查询候选 → 正常历史Huber GMPI → 独立评价。

数值流程见根目录 [WORKFLOW.md](../WORKFLOW.md)，稳定版本及基线见[版本说明](releases/pats-v1.0-21x5.md)。

- `data`负责日期、来源、只读输入映射和BGP源隔离。公开快照、训练来源、最终标签角色分开登记。
- `upstream`包含邻居模型、递归模型和255维路径评分，训练源切分、模型和特征schema由同日清单绑定。
- `pats`负责当前完整流程、源ρ策略、增强入库、批处理候选和恢复。
- `prefix_tree`负责公开关系、阶段、父节点上下文和完整树；同一源的增强、训练、查询使用同一棵树。
- `experiment`与 `downstream`提供准备、调度、训练、选模和评测；训练标签与PATS局部知识必须核验同一入库路径集合哈希。
- `core`保留历史数值实现和checkpoint兼容名称。当前PATS尾段拼接与历史PG分开命名，不为整理目录重命名checkpoint引用。
- `traceroute`使用targets-only查询；最终路径观测只在模型、预测冻结后评分。

输入映射仅读取；写入留在当前run。exFAT不支持符号链接和硬链接，流程不依赖它们，也不复制整个外部语料。大数据、模型、产物分别留在 `data/`、`models/`、`runs/`。

ρ旧版本和March迁移实现保留为历史回归／缓存兼容，不能据其旧文档推断当前默认入口。生产运行不导入 `runs/`中的临时代码或外部 `MetaGMPI_legacy_20261024`。

项目目录用途见根目录 [DIRECTORY_MAP.md](../DIRECTORY_MAP.md)。`tests/`仅放自动化测试，`tools/`放独立核验与数据工具，`scripts/`保留正式启动和运行支撑，`research/`单列独立研究实验登记。

后续新实验在本项目内从稳定标签建立独立分支。输入、路径库、树或数值代码变化必须形成独立身份；相同工件经验证后复用，不能重写旧记录来冒充等价。最终测试标签不参与训练、入库或选模，缺候选按固定分母计零。
