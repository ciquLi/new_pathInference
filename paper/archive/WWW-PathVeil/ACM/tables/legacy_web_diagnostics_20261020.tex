The earlier model returns an endpoint-valid prediction (the predicted source and destination ASes agree with the trace mapping) for 98.02\% of TCP targets and 97.71\% of Paris-traceroute targets. Its node recall is 90.11\% for TCP and 85.47\% for ICMP; KnownPath has higher node precision, recall, and F1 in both protocols. These diagnostics therefore show broader prediction availability but lower agreement with observed AS sets for the earlier model. Intermediate-hop and edge scores are lower in these partially observed traces. No record in either protocol has a continuous, fully mapped TTL sequence from the first hop through the destination, so a strict complete-path exact-match ratio is not estimable from the raw traces.

Using the same assumption-based subset of 2,198 paths, the earlier frozen
model exactly matches 215 ordered sequences (9.78\%), compared with 492
(22.38\%) for KnownPath. The respective pair-wise any-observed-path match
rates are 11.38\% and 26.03\%. These earlier-model sequence diagnostics are
distinct from both the current model's AS-set Jaccard and the empty fully
mapped raw-trace subset.
