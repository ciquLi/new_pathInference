# 独立研究实验

这是同一项目内的研究实验登记区，与正式方法 `src/pathInference/`、软件测试 `tests/`、维护工具 `tools/`分开。

AS34927、AS58057部分吸纳原始TRAIN路径的独立实验见 [partial_train_v1/](partial_train_v1/README.md)。正式21／5基线及包名迁移代码已提交固定，研究扩展位于独立分支。

新实验从稳定标签建立独立Git分支，在 `research/<实验名>/`保存方案、配置、实验入口和对照说明；数值计算遵循项目的 `src/pathInference/`约定，在独立分支中明确隔离扩展。每个实验说明基线版本、改动环节、数据边界、可复用缓存和输出目录，不把临时分析或模拟数据混入正式运行源码。

结果保存到独立的 `runs/<日期>/<实验名>/`，大型数据和已有模型按已验证身份复用。最终标签不用于选择入库路径，原五日期结果不覆盖。
