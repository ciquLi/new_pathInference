# 有向片段逐段对齐评分网络

这是网络结构实验，不是前一轮 AS／路径预训练的延续。20260201 全部十源。
数值实现位于 `src/pathInference/research/edge_alignment_confidence.py` 与
`edge_alignment_experiment.py`，不改变冻结生产模块、路径生成或已有实验代码。

两种新计算图采用同一局部对齐模块、完全相同的初始张量：

- `edge_only`：完全由局部对齐网络打分，原 GMPI 的 `pr/pm` 不参与计算且冻结。
- `gmpi_edge_residual`：原 GMPI 的原始 logit 加上局部对齐修正，然后统一 masked softmax。

本轮改变 AS／路径表示与评分结构，正式训练数据、顺序、AS 向量初值、损失及参数全部固定。
对照是已独立审计的 `gmpi_confidence_v1/query_cross_entropy`。不加载它的训练后权重。
新网络首先按原构造顺序创建 GMPI，逐参数核对其初值哈希；随后创建局部模块。
初始化局部模块后恢复原构造器末尾的 CPU 随机状态。最终修正头从零开始，残差组初始输出等于
同初值的冷启动 GMPI；纯对齐组从候选均匀分布开始。两组不是把已有测试模型继续多训练一轮。

为共用冻结的训练与序列化接口，纯对齐组仍保存不参与计算的 GMPI `pr/pm` 兼容参数。
它们没有梯度、不会更新；总参数和实际可训练参数分别记录在逐模型 `ARCHITECTURE.json`，
独立审计会核对这些未使用权重与初始值完全一致，不能把它们当作实际运行的模型容量。

新结构的内容：

1. 源角色／目标角色投影将每个有向 AS 跳转表示为 `[u, v, u-v, u*v]`。
   两层不同膨胀率的局部卷积编码连续片段，保留方向与顺序；加入距首尾位置表示。
   卷积采用等价的有序窗口矩阵乘法计算，输出与梯度均与 Conv1d 核对，规避旧 CuDNN 对极短序列的慢内核。
2. 在压缩整条路径前，每个候选跳转都与全部有效历史片段做最大相似度匹配。
   使用候选分块限制临时显存，任何真实候选、历史或节点都不能被截断或抽样丢弃。
3. 从同一离散路径计算精确有向二元／三元片段支持、最长有序后缀支持。
   这些是原输入的派生表示，不读取新路由、不赋予 unknown 商业关系，不把观测支持当成转发事实。
4. 由查询端点条件化的门控汇总每跳可靠性、最弱／最强支持、首末跳与后缀证据，输出整条路径分数。
   不对候选集合做自注意力：增加竞争候选只改变 softmax 归一化，不改变旧两条路径的相对 logit。

七项输入与原 GMPI 一致，历史路径完整保留。原始 AS 向量缓存复用前轮 `BASE_VECTORS.npy`，
该文件是原环境初始化向量，不是前轮预训练后的向量；加入快照哈希，并通过原 GMPI 初值重构
进行验证。没有新预训练，不增加公开证据、源内 train 路径、增强路径或测试标签。

损失仍为原查询内软标签 CE（温度 0.1），Adam、源内学习率、batch、上限 30 轮、patience、
种子以及源内 pair-disjoint 弱标签验证均继承同一对照。每源最优检查点只按原验证规则选择。
已知历史测试结果，因此本轮是探索性单种子对照，不按 test 逐源选配置或调整参数。

隔离导入既有数值引擎，仅绑定本实验的配置、输出与模型工厂。两个变体的完整初值相同，
共用原引擎逐源 `INITIALIZATION.json`；变体语义由配置、模型 identity、工厂计算图和
`ARCHITECTURE.json` 一起绑定。每 epoch 保存优化器和 RNG，预测沿用 SQLite 事务与字节偏移。
所有二十模型冻结后预测，所有二十份预测冻结后最终评测。单 GPU、两个 CPU 线程，不改 VS Code。

```bash
/home/lxl/anaconda3/envs/rl-aspath-inference/bin/python -B -u research/edge_alignment_v1/run.py
```

输出在 `runs/20260201/edge_alignment_v1/`，包括每 15 秒刷新的 `PROGRESS.md`、原始逐查询预测、
训练模型、逐阶段 wall/CPU 计时、逐 AS／总体／高低 rho 结果、候选 oracle 差距和容量声明。
结束后自动调用 `tools/validation/audit_edge_alignment.py`，独立核对冻结输入、成对初值、
有效计算图／未使用参数、检查点选择、全局冻结顺序、候选成员、查询分母、最终指标与 CSV。
独立审计通过后，`tools/validation/report_edge_alignment.py` 汇总 GMPI 参考与两种新结构的
总体／高低 rho 差异、逐源升降和实测 wall/CPU 成本，输出 `CONCLUSION.json`、`TIMING.csv`
及 `TIMING_SUMMARY.json`，并补全报告。该工具拒绝未完成或未独立复算的结果。

这是评分网络及其内部派生片段特征的整体结构对照，不能把效果分别归因于单个卷积或支持特征。
分数没有被证明是真实路径概率；无论正负结果都保留，生产方法不自动替换。
