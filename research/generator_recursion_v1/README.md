# 生成器与递归策略消融

固定参照为已登记的五日期21／5结果，配置见 CONFIG.json。实验在独立研究分支运行，正式数值模块不改动。

| 配置 | 候选生成器 | 递归 | 增强库 |
|---|---|---|---|
| current | PATS | 当前条件策略 | 原固定增强库 |
| legacy_generator | 旧高频节点生成器 | 当前条件策略 | 与 current 路径集合及文件完全一致 |
| no_recursion | PATS | 不展开二跳 | 仅用首跳与合法训练尾路径构造 |
| all_recursion | PATS | 每个选中首跳尝试展开，宽度5 | 按展开结果构造 |

只比较 current 对 legacy_generator，以及 current 对 no_recursion/all_recursion。前者只替换训练和测试的候选生成回调；后者只替换递归策略，并让对应树贯穿增强和训练／测试候选生成。所有配置冻结同日公开证据、首跳选择、邻居模型、255列打分器、质量规则、候选上限200、GMPI超参数和种子。高ρ的 all_recursion 与当前策略本来相同，直接复用核验后的库和树。

无递归保留所有选中 `(s,n)`，仍可拼接合法尾路径。低ρ全部递归保留原本有合法尾路径的首跳，并额外尝试二跳；高ρ沿用冻结方法的二跳叶策略。无合法尾路径或可支持二跳的邻居记录为未覆盖，不造路径、不删除AS。

训练／验证按完整源目的AS对隔离。原参照已有的pair保持原划分；递归引入的新pair用固定种子哈希分配，跨配置不换边。缺候选的pair只记录缺失，不挪到另一划分。每个新候选配置单独训练冷启动GMPI；current的最终效果复用冻结结果，重新生成的候选仅补齐已清理的候选诊断。

评测在模型选择完成后独立读取最终标签，统计有候选比例、包含真实完整路径的比例、oracle Jaccard及最终Jaccard／完整匹配。无候选计0；图直连按正式分发规则作为隐式候选。逐AS、按高低ρ和全体汇总。递归组另报真实二跳前缀覆盖、各已观测首跳获得的增强路径数、增强完整路径在TRAIN前向索引的支持率；该支持率不等同于准确率或真实转发证明。保存逐pair oracle用于配对差值和置信区间。
