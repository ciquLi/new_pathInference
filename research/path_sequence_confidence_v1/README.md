# 路径评估网络结构对照

在 20260201 全部十源上，对已完成的 `gmpi_confidence_v1/query_cross_entropy` 做网络结构对照。
原网络含位置编码，不能说它完全不识别顺序；其主要路径汇总依然是对节点表示加权求和，
历史路径先压成一个公共状态，再以同一状态对所有候选点积打分。

进一步核对 `selfAttentionNetwork`：节点 logit 为
`w1(w2(first_hop) + w3(penultimate) + w4(mean_path) + w5(token_j))`，
这些变换之间没有非线性。前三项在同一路径的所有节点间是公共标量，节点 softmax 会抵消它们。
因此这里的注意力权重实际不受前三个条件项调节；这不等于整条路径完全忽略这些节点，
因为它们本身仍在 token 序列中。合成输入检查改变独立 penultimate 输入时，路径汇总最大
变化为 `2.38e-7`；w2/w3/w4 梯度约 `1e-7`，w5 梯度约 `5.10`。
诊断及原文件哈希保存在输出目录的 `GMPI_ATTENTION_DIAGNOSTIC.json`。
这个结构性质不能独自证明历史测试误差的因果来源，新网络效果仍以冻结输入的实证对照为准。

新网络直接使用同一七项 GMPI 输入，不加载额外拓扑、源内 train 路径或 test 路径：

1. 共享原始 AS 嵌入初值；AS 嵌入继续可训练。
2. 有向相邻跳编码 `[previous, current, delta, product]`、距源/距目的位置编码，
   两层 64 维、4 头的路径内自注意力，学习局部连续性及较远跳之间的关系。
3. 每条候选独立关注原本就提供的历史路径，空历史贡献严格为零。
4. 无位置编码的候选集合注意力与非线性打分，让候选比较不依赖枚举顺序。

“有向跳”是从 AS 序列中学习的表示，不是新增的商业关系标签。保持 unknown 语义。
只移除末尾纯 padding 的计算，不截断真实路径或删减真实候选。

这是一组整体网络结构对照，网络容量、内部模块与归纳偏置一起变化；不能把效果单独归因于
Transformer、相邻跳或历史注意力。若整体有收益，再用逐模块消融定位。并不保证大幅提升，
也不声称 softmax 分数已校准成路径真实性概率。

损失仍为 `softmax(weak Jaccard / 0.1)` 的查询内交叉熵。保留同一划分、训练行/候选/历史顺序、
Adam、源内 lr/batch/epoch 上限/patience、种子及弱标签 top1 Jaccard 的检查点选择规则。
初始 AS 向量相同；不同结构的完整初始权重不能声称相同。没有从旧模型热启动。
固定参数一次性预注册，不看 test 调参，不按 AS 定制网络。旧测试已知，属于探索性研究。

复用已审计 GMPI 引擎的训练/断点/预测/事务接口，通过独立 Python 模块实例显式绑定本实验
配置、输出和模型工厂；不更改旧引擎源文件或已导入控制组的全局变量。
新旧输入、候选、增强库和代码均以 SHA256 绑定；训练/验证仍与相同 admitted library 关联。
全部十模型冻结后才预测，全部十预测冻结后才评测。每 epoch 与每批预测可续跑。

一个 GPU 工作进程、2 CPU 线程，复用环境与嵌入；不触碰 VS Code 图形加速。

```bash
/home/lxl/anaconda3/envs/rl-aspath-inference/bin/python -B -u research/path_sequence_confidence_v1/run.py
```

输出在 `runs/20260201/path_sequence_confidence_v1/`：`PROGRESS.md`、逐源模型、预测、
训练/预测/评测的实测 wall/CPU 时间、`REPORT.md`、`RESULTS.csv`、`SUMMARY.json`。

检查点、模型、候选成员、逐源分数及查询总数，写 `COMPLETION_AUDIT.json`。
原 LightGBM 对照继续独立运行，不改它的代码或冻结资产。

首轮已完成并独立审计通过：20260201 十源共 685,820 个查询，所有候选成员关系及逐源/总体/
高低 rho 分组结果均复核一致。新网络 Jaccard 为 `0.825380979`、完整路径匹配率 `55.0462%`；
同输入 GMPI 交叉熵组为 `0.849779018`、`57.9850%`，分别下降 `0.024398039` 和 `2.9388` 个百分点。
只有 AS328840 优于交叉熵组（`0.800956 -> 0.823595`），且仍低于原 Smooth L1 组的 `0.833297`。
该整体结构方案未验证准确率收益，不能按测试结果逐源挑选新旧模型并声称受控改进。

新网络各源训练阶段 wall 时间合计 `878.45 s`，预测阶段合计 `1643.71 s`；
GMPI 交叉熵组对应为 `1069.85 s` 和 `2334.57 s`。这些是实际运行阶段耗时，第一源训练包含
环境加载，各组与 CPU 任务的并行负载也可能不同，不据此宣称隔离条件下的普遍加速比。
结构中可证明的注意力抵消问题不等于改动后必然提高 held-out 准确率；本轮结果保留为负对照。
完整逐源结果和审计见输出目录 `REPORT.md`、`RESULTS.csv`、`COMPLETION_AUDIT.json`。

冻结结果的事后诊断显示：十源中有五源的最佳弱标签验证 Jaccard 提升，但其中四源的最终
Jaccard 反而下降；只有 AS328840 同时提升。明细保存为 `VALIDATION_TRANSFER_DIAGNOSTIC.json`。
因此不能仅凭增强库内的弱标签验证分数判断结构改动能否改善最终选路。这提示需要检查监督信号
和任务迁移的一致性，但不构成误差来源的因果证明，也不据此进行 test 分源选模或本轮调参。
