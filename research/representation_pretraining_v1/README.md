# 固定路径生成后的 AS 与路径表征学习

20260201 全部十 AS；新实验在研究分支中实现，生产代码与历史实验模块不改。
输出：`runs/20260201/representation_pretraining_v1/PROGRESS.md`。

三档逐因素对照：

1. 冷启动：复用已完成且独立审计通过的 `path_sequence_confidence_v1/ordered_path`。
2. `as_context`：网络结构完全相同，只增加 AS 向量的有向相邻跳自监督初始化。
3. `as_and_path`：从第二档同一 AS 预训练权重开始，只增加路径编码器预训练。
   这一阶段固定 AS 嵌入，更新路径编码/汇总参数，保持历史交互、候选交互和最终打分头初值不变。

正式微调时，两档新配置的全部参数均允许训练；Adam、学习率、batch、最大 epoch、patience、
查询内软标签交叉熵温度、种子、训练与验证查询及行顺序，都继承冷启动对照。
微调开始的随机状态与冷启动创建网络后的状态相同，辅助训练不会消耗正式训练的随机序列。
新旧初始化、预训练前后变化的参数、候选与库哈希都有记录；辅助头不进入排序网络。

固定上游：公开证据、树与邻居、增强库、训练/测试候选实际字节、历史路径、词表和划分均复用。
不调用路径生成，不新增源内 train 路径或外部语料。语料仅取每源同一 admitted library 中
端点属于 train_pairs 的完整路径，排除 validation_pairs 与其他端点；逐条验证长度、词表，
不得截断、补造节点或将未知 AS 静默映射到 padding。库路径集合哈希必须与训练和候选 PG 绑定一致。

AS 任务：预测增强库训练路径中给出的有向下一跳，使用抽样识别损失，屏蔽训练语料中该前驱的
其他已出现后继，避免把它们误作负例。这里的路径仍是合成增强路径，不当作实测转发事实。
只改变 AS 嵌入；用于预测的有向投影头会丢弃。

路径任务：每条路径遮住一个内部 AS（两节点路径遮目的 AS），用不含端点/倒数第二跳旁路的
上下文 token 恢复该节点。另用两次 dropout 视图学习整条路径表示，屏蔽同端点路径间的负例。
原始离散路径没有删改并重新登记为真实路径；mask 只是辅助训练输入。
识别目标不宣称未抽中的节点是非法转发；对比目标不预测邻居份额。

该实验借鉴 RED 的掩码路径学习、AutoPRL 的节点/路径两级学习；属于 AS 路径上的适配实验，
并非原论文完整复现。首轮每源训练语料只有约 900～4,600 条，不等同大规模跨源预训练。
参考：[RED](https://github.com/slzhou-xy/RED)、[AutoPRL](https://arxiv.org/html/2610.35032v1)。

超参数在 `CONFIG.json` 预先固定。辅助训练固定轮数，不用验证或 test 选轮数；正式微调
仍按原 pair-disjoint 弱标签验证选检查点。已有历史 test 结果已知，本轮为探索性实验；
不能按 test 逐 AS 选择不同配置再当作统一方法结果。

单 RTX 3090 工作进程、2 CPU 线程，按阶段批量处理 10 个 AS；已完成阶段校验哈希后跳过。
辅助和正式训练均保存 epoch、优化器和 RNG 状态，预测复用已有 SQLite 事务/字节偏移接口。
所有 20 模型冻结后才预测，所有 20 份预测冻结后才读取最终评测标签。
进度每 15 秒更新，实际工作量以 epoch 和已落盘查询计数为准；不修改 VS Code 图形加速。
